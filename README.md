# AnDTix Event API

AnDTix is an Africa-first, globally scalable serverless event registration and ticketing API built with AWS services.

The project allows users to:

- View available events.
- Register for an event.
- Retrieve registrations using an email address.
- Prevent duplicate registrations.
- Cancel an existing registration.
- Automatically build, test and deploy changes through GitHub Actions.
